# Giphy Search — Leaderator Project 2

A GIF search app built with **vanilla JavaScript** and the [Giphy API](https://developers.giphy.com/), made as the second project of Bank of Georgia's Leaderator front-end bootcamp (2022).

## Features

- **Search** GIFs by keyword
- **Trending** — load what's currently trending on Giphy
- **Suggestions** — quick-search buttons, updated with your recent searches (keeps the last 6)
- Results rendered dynamically into a responsive grid

## What it covers

- `fetch` with `async`/`await` against a REST API
- Building DOM elements from JSON responses
- Event handling and simple client-side state

## Running locally

No build step needed. Clone the repo and open `Giphy.html` in your browser, or serve the folder with a local server (for example, the VS Code Live Server extension).

```bash
git clone https://github.com/TaTamta/Project-2.git
```

The app uses a Giphy API key in `giphy.js`. Giphy keys for browser apps are client-side by design; if this one stops working, create a free key at [developers.giphy.com](https://developers.giphy.com/) and replace it.
